# AdamHook для HOI4 1.19.3

Обновление исходного AdamHook (автор SilverXV) под установленную Windows Steam-сборку **Operation Postern v1.19.3.0.c01a (5632)**.

## Запуск

1. Запусти HOI4 и загрузи сохранение.
2. Запусти `AdamHook.exe` из папки `AdamHook-1.19.3` в готовом архиве.
3. Для Tagswitch используй положительный числовой ID страны из Tdebug текущей игры.

Требуется Windows x64 и .NET Framework 4.8. При другой сборке `hoi4.exe` программа отключает кнопки и сообщает о несовместимости. После закрытия и повторного запуска игры нужно перезапустить AdamHook.

## Изменения

- Обновлены адреса FOW, AllowTraits, Debug, Tdebug и текущей страны.
- Вместо нулевых адресов заданы адреса переключателей исследований, строительства, дипломатии, целей войны, тренировки и фокусов.
- Tdebug записывает один байт; исправлены проверки чтения и записи памяти.
- Добавлены проверка SHA-256 исполняемого файла, обработка ошибок, блокировка кнопок до подключения и повторное разрешение указателей.
- Исправлено время жизни аудиопотока; сборка выполняется для x64.

## Что проверено

Сборка Release x64 прошла. Адреса проверены статически по обработчикам команд установленного `hoi4.exe`. Тесты чтения/записи выполнены на памяти отдельного тестового процесса.

**В запущенной игре функции ещё не протестированы.** Работа в мультиплеере не подтверждена. Tagswitch сохраняет прямую запись ID из исходного проекта и не повторяет все действия консольной команды игры. Подробности и адреса — в `COMPATIBILITY.md`.

## Исходники

Решение: `AdamHookAlpha.sln`. Для обычной сборки установи Visual Studio с инструментами разработки настольных приложений .NET и .NET Framework 4.8 Developer Pack; запусти `BUILD.ps1` или выбери Release / x64 в Visual Studio.

Готовый архив содержит программу в `AdamHook-1.19.3/` и исходники в `source/`.
