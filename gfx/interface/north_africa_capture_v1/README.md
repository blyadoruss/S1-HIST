# Северная Африка: части карты для GUI

Участок: Тунис, Ливия и Египет, включая Синай. Геометрия получена из текущих `map/provinces.bmp`, `map/definition.csv` и файлов штатов мода. Это плоская карта без перспективных искажений скриншота.

## Файлы

- `bands/` — 6 горизонтальных рядов, пронумерованных с севера на юг. Каждый ряд представлен отдельными `green`, `red` и `neutral` PNG.
- `provinces/` — 165 отдельных сухопутных провинций, по три PNG с теми же цветами. Две озёрные провинции не включены в маски территорий.
- `north_africa_green.png`, `north_africa_red.png`, `north_africa_neutral.png` — полные карты для просмотра и использования в качестве основы.
- `previews/overview.png` — обзор набора. Надписи присутствуют только в обзоре.
- `previews/capture_example.png` — пример с тремя зелёными и тремя красными рядами.
- `manifest.json` — номера провинций, штатов, рядов, размеры и координаты.

## Размещение в GUI

Все PNG имеют настоящий прозрачный фон (RGBA). У трёх вариантов одной части полностью совпадают размеры и альфа-канал.

Размер общей карты: **1371 × 1017 пикселей**. Все изображения из `bands/` размещаются в одной позиции `(0, 0)` внутри контейнера карты. Отображайте ровно один цветовой вариант каждого ряда. Внутренние вертикальные границы провинций в рядах скрыты.

Изображения из `provinces/` обрезаны до собственных границ. Размещайте их по полю `position` в манифесте; оно задано относительно того же общего холста. При уменьшении карты применяйте один коэффициент и к размерам, и к координатам.

Ряды состоят из **целых провинций**: каждый контур принадлежит только одному ряду. Распределение сделано по вертикальной координате центра провинции, с приблизительно одинаковым числом провинций в ряду. Поэтому границы следуют игровым контурам и не являются идеально прямыми линиями.

Для проверки захвата используйте `province_ids` нужного ряда. Правило переключения цвета (захвачены все провинции, большинство или ключевая провинция) задаётся в вашем GUI отдельно. Набор содержит изображения и привязки, но не добавляет игровые триггеры или интерфейс.

Исходный генератор: `tools/build_north_africa_gui_assets.py` в корне мода. Он не изменяет карту и не перезаписывает готовый набор.
